# 下位机平台远程接入

## 目标与边界

下位机主进程增加独立 PlatformAgent 连接功能，主动接入平台已有 gRPC 入口。平台在线能力不依赖 ConfigPusher、业务模块启停或现场采集任务。默认禁用，不改变现有模块配置来源。实现后用户另外授权 x64 服务器隔离编译测试；不部署、不操作真机或既有服务。

规范协议为 MskDSPPlatformProto 的 `platform/v1/remote.proto`；本仓库固定镜像位于 `platform-proto/platform/v1/remote.proto`，通过独立 `platformRemoteProto` 目标生成，业务 `protobuf` 子模块不变。变更镜像前应与三端规范同步并核对字节一致。

## 输入、输出与目标解析

连接功能使用环境变量配置；设备令牌仅从环境读取，不保存、不输出。启用后先发送 Hello，然后按照 Welcome 的间隔发送心跳，心跳携带当前可用服务完整集合。连接失败自动重连，重连不恢复旧隧道或重放业务字节。

Hello 的 `agent_version` 为组件协议标识 `platform-agent.v1`，用于区分平台连接组件协议能力，不是下位机发布版本。

| 环境变量 | 默认值与用途 |
| --- | --- |
| `MSKDSP_PLATFORM_ENABLED` | `0`；设为 `1` 启用连接功能 |
| `MSKDSP_PLATFORM_TARGET` | 必填，平台 gRPC 主机名与端口 |
| `MSKDSP_PLATFORM_DEVICE_ID` | 必填，平台注册的设备 ID |
| `MSKDSP_PLATFORM_DEVICE_TOKEN` | 必填，设备专用令牌 |
| `MSKDSP_PLATFORM_CA_FILE` | 可选 PEM 根证书；为空使用系统默认根证书，验证主机名 |
| `MSKDSP_PLATFORM_INSECURE` | `0`；仅本机开发平台可显式设为 `1`，目标限制为环回地址 |
| `MSKDSP_PLATFORM_MODULES` | 逗号分隔模块白名单，默认包含现有业务模块；不接受地址、路径或通配符 |
| `MSKDSP_PLATFORM_MANAGER_PORT` | `17000`，本机管理服务端口 |
| `MSKDSP_PLATFORM_SSH_ENABLED` | `0`；设为 `1` 公布 `ssh` 服务 |
| `MSKDSP_PLATFORM_SSH_PORT` | `22`，本机 SSH 端口 |

`ModuleManager` 固定映射本机环回管理服务；普通模块必须位于白名单，且在本机 `GetRunningModuleInfo` 返回的运行集合中。仅提取已知模块监听端口并连接 `127.0.0.1`，不跟随返回地址的 IP。`ssh` 必须本机显式启用。远端不能提交目标 IP、端口或 Unix socket 路径。

## 隧道生命周期与异常

收到 TunnelRequest 后，先重新查询运行模块、校验服务，再连接本机目标；成功后才 AttachTunnel，失败发送中文 TunnelFailure。每设备最多 16 条活跃隧道；每帧最多 64 KiB，空帧和半关闭后数据均拒绝。采用同步流直接背压，不建立无界队列。

本机 TCP EOF 只发送 half_close；平台 half_close 只关闭本机 TCP 写端。保留另一方向直到半关闭完成或收到关闭/取消。握手 10 秒、连接目标最多 5 秒、发送阻塞最多 30 秒。控制流停止、心跳失联、主进程请求停止时取消所有隧道，唤醒阻塞 socket 和 RPC 并回收线程。

日志仅包含消息类型、设备 ID、服务、隧道 ID、方向、字节数和中文关闭原因；不记录令牌、票据、原始业务数据及终端内容。

## 测试与验收

先增加测试再实现：目标白名单、模块端口重映射、非法地址拒绝、默认禁用和 TLS 配置；假平台与本机 echo 服务验证主动连接、双向二进制转发、半关闭尾部、停止取消及连接失败通知。测试使用随机端口。

本机可以运行 `python script/dev/test_platform_agent_contract.py` 进行 protoc 编译，以及 `python script/dev/check_platform_agent_config.py` 使用现有 clang++ 编译并运行标准库范围的真实配置与目标解析检查，不安装依赖。

C++ GTest 可在 Linux/vcpkg 环境运行 `platformAgent_test`。现场 SSH、ARM64、网络抖动及真实业务模块联调需另行确认范围，不以协议、纯逻辑和假平台检查代替现场验收。
