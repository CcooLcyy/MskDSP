# 协议连接通断状态显示设计

## 目标

在上位机协议接入页面的连接名称旁显示通信通断状态：绿色表示当前协议连接已建立，红色表示当前未建立或已断开。连接功能是否启动仍由现有运行状态表示，两者不混用。

## 本次范围

本次先实现已有可靠连接事件或会话状态的协议：

- IEC104：跟踪 TCP 会话建立和关闭，并补齐 IEC104 `TESTFR_ACT/TESTFR_CON` 的响应超时判定。
- IEC61850 MMS：复用现有 A/B 通道 `CONNECTED` 状态；任一启用通道连接时显示绿色，全部断开、错误、连接中或 IED 停止时显示红色。

Modbus TCP、Modbus RTU、DLT645 先不改变通断判据。它们需要后续按“主动轮询收到合法协议响应”设计在线判定，避免把串口句柄或 MQTT 通道在线误认为现场设备在线。

## IEC104 判定

- TCP 客户端连接建立或服务端接受连接后，连接状态为 `CONNECTED`。
- 会话读写失败、对端关闭、IEC104 建链超时、未确认 I 帧超时或测试帧响应超时后，连接状态为 `DISCONNECTED`。
- 客户端自动重连期间状态为 `CONNECTING`；服务端监听但没有客户端会话时为 `DISCONNECTED`。
- `LinkState` 继续表示连接功能的启停，不改其现有语义。

## IEC61850 判定

- IED 启用 MMS 且任一 A/B 通道为 `CHANNEL_STATE_CONNECTED` 时显示绿色。
- 所有通道均为停止、禁用、连接中、断开或错误时显示红色。
- 现有 IED/通道详细状态继续保留，用于诊断具体通道和错误原因。

## 接口与显示

- IEC104 `LinkInfo` 增加独立的 `connection_state` 字段，不复用 `state`。
- 上位机列表和详情标题均在连接名称左侧显示状态点；绿色仅对应 `CONNECTED`，其它状态显示红色，悬浮提示显示具体状态。
- IEC61850 直接根据 `IedInfo.channels` 和 `IedInfo.state` 计算状态点，不新增协议字段。
- 页面沿用现有刷新机制；本次不引入推送通道。

## 验收标准

1. IEC104 客户端 TCP 建立后，列表和详情名称旁状态点变绿。
2. IEC104 服务端接受连接后状态点变绿；客户端关闭或会话错误后变红。
3. IEC104 客户端重连期间状态点不显示绿色，重新建链后恢复绿色。
4. IEC104 空闲对端不响应 `TESTFR_CON` 时，在配置的响应超时后状态点变红。
5. IEC61850 任一 MMS 通道已连接时状态点为绿色，全部通道断开或 IED 停止时为红色。
6. Modbus TCP、Modbus RTU、DLT645 的现有运行状态和页面行为不被本次修改改变。
