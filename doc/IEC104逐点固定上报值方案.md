# IEC104 逐点固定上报值

## 已确认需求

上位机可为从站点表中的某个 IOA 启用固定值。设为 10 后，对端收到的该 IOA 数值为 10，不使用该点的倍率或偏移。其他点继续走原有数据路径。关闭后恢复真实数据与原有换算参数，参数本身不删除。上下位机同时支持，固定值随点表持久化，上位机退出或下位机重启不丢失。

## 范围和接口

- 使用原有 UpsertPointTable/GetPointTable 接口，不改变配置下发来源和连接方式。
- Point 新增 `bool fixed_value_enabled = 13` 和 `double fixed_value = 14`。旧配置缺省为关闭；新配置通过原有点表存储保存。
- 只允许遥测/遥信上报点启用，从站执行覆盖。主站接收和遥控/遥调命令不改变。
- FLOAT 固定值必须有限且能表示为有限的 IEC104 单精度浮点数；SINGLE 固定值只允许 0 或 1。关闭时保留固定值供下次启用。
- 固定值是报文数值，不是工程量；不经过 scale/offset 或反向换算。原工程量参数仍保留并按原规则校验。

## 发送行为

- 真实采集及 DataCenter 数据不修改；所有从站点值出口统一以固定值优先，优先级高于临时模拟值。
- 总召应包含已设定的固定值，即使该点没有真实数据或 DataCenter 快照查询失败。
- 沿用现有点表更新约束：先停止链路功能，保存点表后恢复原有运行状态，不新增在线热更新接口。关闭会话清空旧排队报文，避免配置生效后发送旧值。
- 从站会话进入可传输状态后，对固定点主动发送一次固定值；关闭固定值并重新运行链路功能后尽可能取得最新真实值发送，无数据时等待正常更新。启动链路功能时尚未接入主站，不能仅在启动瞬间尝试发送而丢失这次主动上送。
- 后续沿用原有发送触发机制，不新增周期。真实源更新不能泄漏实际数值；同一固定遥信不因真实源变位形成假 SOE。
- 固定值采用有效品质和发送时刻的时标；遥信基线与实际对外值一致。解除固定值后恢复真实品质、时标和正常变位判定。
- 临时模拟生成、应用、清除不得覆盖已启用固定值的点，也不得清除持久化设置。
- 固定点的首次发送直接从配置构造，不依赖 DataCenter 查询。恢复真实值的查询必须设超时，避免协议发送线程无限等待；已有实时变位基线不能被查询到的旧快照覆盖。
- 固定模式下暂停该 IOA 的历史 SOE 回放，保留历史原值与真实未确认状态，不伪造确认；关闭固定模式后恢复原有历史回放规则。

## 上位机

- 在从站遥测/遥信单点编辑中增加固定值开关和输入。遥测输入数值，遥信选择 0/1。
- 开启时倍率、偏移置灰，提示“固定值模式下不生效”，关闭后恢复编辑，保留原值。
- 列表显著显示固定值状态和实际发送的固定数值，避免实时源值被误认成发送值。
- 点表读取、保存、复制、离线工作区、导入导出均保留新字段；旧数据兼容。
- 变更类型或业务类型时不得留下非法固定值配置。保存与实际执行增加中文日志。

## 验收和验证

1. 非单位倍率、非零偏移下固定为 10，总召与自发报文都发送 10；未固定点保持原换算。
2. 固定值为 0、不带真实快照、真实更新、模拟值覆盖尝试、清除模拟值等场景均保持固定值优先。
3. SINGLE 0/1 正确发送；真实变位不生成虚假 SOE；改变或关闭固定值后基线正确恢复。
4. 点表持久化往返和模块重建保留设置；旧点表缺省为关闭。
5. 非有限值、溢出 FLOAT、非法 BOOL 和非上报业务启用固定值应返回中文 INVALID_ARGUMENT。
6. 上位机保存、重载、复制、导出后设置不丢失，倍率与偏移不被改写。
7. 固定点首次发送不调用 DataCenter；关闭固定同时改名也能按 IOA 找到原固定状态并恢复最新值；恢复快照不回退已推进的遥信基线。
