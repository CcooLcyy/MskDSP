# AGC/AVC 控制模式与周期调度方案

## 目标

为 AGC、AVC 控制组增加可切换的控制模式，保持现有 PI 事件控制行为不变，同时提供符合标准定义的周期直分配模式：

- 计算执行周期：1～15 秒可配置；
- 命令控制周期：4～30 秒可配置，约束控制模块向下游设备输出新设定的最小间隔。

## 控制模式

模式按控制组配置，不做模块全局切换：

- `PI_EVENT`：现有事件触发控制。输入值变化即触发计算，使用 AGC 固定控制参数、积分记忆、单步限制和爬坡限制；AVC 目标电压模式继续使用现有电压死区和比例调节。
- `DIRECT_CYCLIC`：周期直分配控制。AGC 以及 AVC 的 `q_total_cmd` 模式按计算周期执行计算，直接按最新目标和量测分配，不使用 PI 积分/比例补偿；命令输出受命令控制周期限制。AVC 目标电压模式不允许配置为该模式。

两种模式不能同时运行。切换模式要求控制组停止后更新配置并重新启动。

## 周期模式调度

周期模式维护以下运行态：

- `pendingTarget`：最近一次计算出的待下发成员设定；
- `lastAppliedTarget`：最近一次成功发布到 DataCenter 的成员设定；
- `lastCommandPublishedAt`：最近一次成功发布控制命令的时间。

输入事件只负责更新最新值缓存，并通知周期线程检查运行状态；该通知不得使计算早于下一个计划计算时点。周期线程按 `calculation_execution_period_seconds` 执行计算。计算结果始终覆盖旧的待下发目标，命令控制周期满足后只发布最新目标。

首次启动或模式切换后的第一轮允许立即计算并下发，不额外等待一个完整周期。

## 同步命令语义

经 `DataCenter.ExecuteCommand` 进入周期模式的命令：

- 先执行功能投入、远方操作、目标点、量测和可调范围等现有合法性校验；
- 校验通过后只保存最新目标并返回 `COMMAND_ACCEPTED`，说明为“命令已接受，等待周期调度下发”；
- 到达计划计算时点后使用最新缓存计算；若仍处于命令间隔内，则覆盖待下发目标并等待后续周期，只保留最新结果；
- 不在 DataCenter/协议层伪造已完成的下游执行确认。

异步订阅输入同样只保留最新值，避免命令堆积。

## PI 状态隔离

周期模式不读取或写入 PI 的积分记忆、固定控制参数和 PI 上一轮目标。切换模式或停止控制组时清空：

- PI 积分记忆；
- 周期模式待下发目标；
- 周期模式最近下发时间和应用目标缓存。

## 配置与校验

AGC、AVC 的 `GroupConfig` 增加：

- `control_mode`；
- `calculation_execution_period_seconds`；
- `command_control_period_seconds`。

`DIRECT_CYCLIC` 模式要求计算执行周期为 1～15 秒、命令控制周期为 4～30 秒。`PI_EVENT` 模式允许省略周期字段；显式填写时仍校验范围。上位机按模式展示对应字段，ConfigPusher 原样下发。

## 验收标准

1. 未配置模式的旧 AGC/AVC 配置行为与当前版本一致。
2. 周期模式计算不会快于配置的计算执行周期。
3. 周期模式向下游发布命令的相邻成功发布时间间隔不小于命令控制周期。
4. 命令间隔内的新目标不会丢失，周期到期后发布最新目标。
5. PI 模式的积分、步长、爬坡和现有事件触发测试继续通过。
6. AGC、AVC、ConfigPusher、上位机 DTO/表单和配置导入导出均支持新增字段。
