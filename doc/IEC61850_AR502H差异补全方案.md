# IEC 61850 下位机 AR502H 差异补全方案

## 1. 目标

补齐 MskDSP 与 AR502H `module61850` 业务源码之间已经确认存在的 IEC 61850 下位机客户端差异，保持自研 MMS/ISO-on-TCP 协议栈和 ARM64 交付路径不变。

## 2. 对比边界

AR502H 的 `libiec61850comm.so` 是预编译协议库，头文件中声明了比应用实际使用更多的能力。本次只把 AR502H `module61850` 中能确认存在实际调用链的业务补入 MskDSP：

1. 远端文件目录查询和文件下载，用于故障录波/COMTRADE 文件同步。
2. 设定组/SGCB 业务：读取组状态、选择编辑组、修改确认、取消编辑、激活组和召回组。
3. MMS Identify：读取远端厂商、型号和版本，供启动日志和兼容性判断使用。

以下能力在本批次以自研协议层实现，并明确不把 AR502H 头文件或动态库符号视为现场业务已验收：MMS Journal 客户端、动态 Named Variable List/DataSet 管理、MMS 文件写入/删除/改名、SV 发布器和第一阶段 MMS Server 模型分发器。AR502H 模块源码目前未调用这些入口，因此默认关闭，只有显式配置/测试调用才启用。

### 2.1 能力边界与默认策略

- Journal 只读：支持 JournalStatus、InitializeJournal、ReadJournal 的时间范围和 EntryID 游标，输出统一的历史事件/告警/SOE 结构；不实现没有业务依据的 WriteJournal。
- 动态 DataSet 只管理运行时 Named Variable List：CreateDataSet/DeleteDataSet 必须经过在线能力协商、串行 MMS 队列和 RCB 绑定检查；固定 SCL DataSet 不走动态变更路径。服务端未声明的服务不会写入 Initiate 服务能力位。
- 文件写入扩展只在调用方明确请求时启用，采用临时文件、分片上限、大小上限、取消和原子替换；下载/目录的既有流程保持兼容。
- SV 发布只使用现有 AF_PACKET/VLAN/实时线程和双网端点，离线编码、lo/raw 和时序测试不等价于真实双网卡 IED 互操作验收。
- MMS Server 分阶段提供建链、Initiate、目录、Read、Write、控制和最小报告/RCB 闭环；未实现的可选服务在能力位中明确为不支持。

## 3. 文件服务范围

实现 MMS FileDirectory 和 ObtainFile（FileOpen/FileRead/FileClose）客户端流程：

- 目录请求支持路径和有界结果数量；AR502H实际使用的远端目录形式
  `/COMTRADE/` 以及文件形式 `/COMTRADE/<filename>` 均可直接传入；
- 文件下载按服务端返回的文件句柄和分段响应拼接；
- 下载写入调用方指定的临时文件，完成后原子改名；
- 远端路径允许协议服务常用的首尾 `/` 或 `\\`，但拒绝父目录穿越和中间空路径组件；
- 本地目标允许调用方指定的绝对文件路径（AR502H使用例如
  `/tmp/gzlb/IED.../<filename>`），仍拒绝父目录穿越、空路径和目录目标，以及超出本地大小上限的文件；
- A/B 通道沿用现有活动通道和超时/重连策略；
- 目录、分段、句柄关闭和失败原因写入中文协议日志。

文件服务采用 ISO 9506-1 的原始标签约定：FileOpen/Directory 为构造上下文标签，
FileRead/FileClose 请求为原始上下文标签；文件名按 GraphicString 序列编码，目录项
按文件名和 FileAttributes（大小、可选 GeneralizedTime）解码。下载只允许写入调用方
指定的普通文件，先写同目录临时文件，全部分段且 FileClose 完成后再替换目标文件。

## 4. 设定组/SGCB 范围

SGCB 不新增固定厂商对象，而由配置提供 `$NumOfSG`、`$ActSG`、`$EditSG`、`$CnfEdit`、`$LActTm` 等引用。高层操作必须复用现有串行 MMS Read/Write 队列：

- `ReadSettingGroupStatus`：读取 NumOfSG、ActSG、EditSG 和 Last-Activation-Time；
- `SelectSettingGroup`：校验组号后写 EditSG；
- `ConfirmSettingGroupEdit`：写 CnfEdit=true；
- `CancelSettingGroupEdit`：写 CnfEdit=false；
- `ActivateSettingGroup`：写 ActSG；
- `RecallSettingGroup`：按 AR502H 流程读取/写入 EditSG、CnfEdit 并恢复活动组。

所有组号、布尔值、时间和对象引用在发送前校验；失败时不更新本地状态。

## 5. 验收标准

- 编解码测试覆盖正常、空结果、分段、句柄关闭、路径越界和响应错序；
- SGCB 测试覆盖组号边界、写入顺序、取消/确认和远端错误；
- 工作器测试证明扩展请求与报告接收共存，A/B 活动通道切换后请求仍可执行；
- 真实双网卡、真实 IED、长期运行和现场故障录波文件验收仍单独进行，不以单元测试替代。
