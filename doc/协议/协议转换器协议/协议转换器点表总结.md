# 协议转换器点表总结

## 1. 文档来源

- 原始文档：`doc/协议/协议转换器协议/【安全修订】户用三相光伏并网箱技术规范书.docx`
- 本文用途：从原始 Word 中提炼“协议转换器/规约转换器”点表，便于在本项目中落地 `DLT645PCD` 点表与上位机对接说明。
- 分析范围：
  - 附录 C `表C.1 转换器工作参数配置表`
  - 附录 D `表D.1 转换器数据采集与控制数据`
  - 附录 F.6 `数据标识定义`
  - `运行状态字` 定义

说明：

- 本文是分析与落地草稿，最终以原始 Word 文档为准。
- 如需在本项目中配置 `point_table`，建议以附录 F.6 的 `DI` 映射为准，以附录 D.1 的业务分类和命名为辅。

## 2. 总体结论

原始文档里的“点表”不是单独一张表，而是分为三层：

| 层次 | 作用 | 对应表 |
| --- | --- | --- |
| 工作参数层 | 描述转换器自身可查询/可配置参数 | 表 C.1 |
| 业务语义层 | 按运行类、状态类、统计类、参数类、控制类整理业务点 | 表 D.1 |
| 规约映射层 | 给出每个数据项对应的 `DI`、长度、码制、单位、读写能力 | 附录 F.6 |

结论如下：

- 这份 Word 足够整理出一版可用的协议转换器点表。
- 如果要落到本项目 `DLT645PCD`，附录 F.6 才是最关键的“规约层点表”。
- 附录 D.1 更适合作为上位机页面分组、标签命名、联调口径说明。
- 当前仍有少量语义口径需要联调前确认，见文末“待确认项”。

### 5.2 运行状态字

`DI = 02F10005`

文档给出的核心语义如下：

| 位/位段 | 含义 | 说明 |
| --- | --- | --- |
| bit6 | 运维 | `0`：非外网远程运维；`1`：外网远程运维 |
| bit5 | 逆变器故障 | `0`：无故障；`1`：有故障 |
| bit4 | 转换器与逆变器通信状态 | `0`：离线；`1`：在线 |
| bit3..bit0 | 逆变器运行状态 | `0000` 正常发电；`0001` 出力受控；`0010` 待机；`0011` 停运；`1111` 关机 |
| bit12 | 停电 | 文档定义为停电标志 |
| 其他位 | 保留 |  |

建议：

- 若上位机需要独立展示“通信状态、运行状态、故障、远程运维、停电”，建议统一从 `运行状态字` 派生。

## 6. 建议的首版 DLT645PCD 建模方式

结合本项目当前 `DLT645` 模块能力，建议先按“块读 + 单点读写”的思路建模。

| 数据块 DI | 建议用途 | 子项 |
