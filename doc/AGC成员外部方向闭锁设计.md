# AGC 成员外部方向闭锁

AGC 可控成员可独立选配「禁止增出力」和「禁止减出力」遥信。上位机为所选协议 BOOL 点配置到 AGC 控制组的输入路由，并在 `MemberConfig.increase_block_input`、`decrease_block_input` 中保存对应的目标 tag。输入只接受原始 BOOL，不做工程量换算。未选方向继续沿用原有行为；成员外部闭锁不改变组级只读「AGC增闭锁」「AGC减闭锁」的设定值到限口径，也不改变 AVC。

每路只有 GOOD 且无异常品质位的 BOOL 更新才有效：true 置位，false 解除；无效类型或品质不置位，也不清除已置位状态。旧时间戳不能覆盖较新的有效状态。进程重启或控制组配置替换后没有闭锁历史，以 DataCenter 当前有效输入建立状态；若尚未取得任何有效值，该方向按未闭锁处理。控制组重新启动控制功能时，在首轮下发前读取当前闭锁和量测快照，避免先处理总命令快照时遗漏已有闭锁；快照读取失败则暂缓输出，事件触发模式约每秒重试一次，周期分配模式按计算周期重试。绑定只允许可控成员使用，输入 tag 不得与总命令、量测、设点、派生点、生效的增量基准、通信状态或 AGC 保留标签冲突；允许复用同一个源 BOOL 点，每个成员每个方向使用独立的 AGC 组内目标 tag。

闭锁约束成员的绝对设定值，以最近成功发布到 DataCenter 的成员绝对设定为边界；没有成功发布过时，以有效有功量测为边界。计算结果、限频跳过和发布失败均不更改边界。没有有效边界时，不向该闭锁成员写设点，未知出力不作为分配贡献；若量测边界与静态最小/最大值冲突，且两类约束无法同时满足，也不写该成员，以已知出力作为固定贡献。增、减同时闭锁且有边界时保持该边界。

先按原权重分配，再对越出成员可行区间的目标截断；差额交由该方向仍有空间的成员按权重承担。PI 校正后仍受同一区间约束。同步命令按未施加外部闭锁时的原有能力判定越限；仅因外部闭锁暂时无法完成的目标照常接受并保留，按当前可行值发布。现有组级可调上下限仍采用原口径。有效闭锁变化触发 PI 事件计算；周期直分配继续遵循计算周期及命令限频。解除后沿用原总目标，增量总命令不重复叠加。

验收复用现有 AGC 下位机单元测试框架：覆盖单向及双向行为、好坏品质、首次量测基准和缺测、成功设点边界、PI/周期模式解除后恢复、临时闭锁与原有越限拒绝的区分。现有组级到限闭锁用例和端到端用例照旧。编译及自动化测试由 CI 执行。
