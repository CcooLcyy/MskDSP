# Modbus RTU 采集品质与 IEC104 上送

RTU 按点保存最近成功采样的值和时间，独立于数值死区和已上报基线。首个有效样本到达前不发布占位值，104 主动上送及总召省略无缓存样本的点。

| 采集结果 | 已有样本的品质 | 值及时标 |
| --- | --- | --- |
| 读取及解码成功 | 0，正常 | 本次样本 |
| 超时、CRC 或其他通信故障 | NT（0x40），非当前值 | 最近成功样本 |
| 有效 Modbus 异常响应、点解码或换算失败 | IV + NT（0xC0），无效且非当前 | 最近成功样本 |
| 手动停止采集 | 原品质加 NT | 最近成功样本 |

RTU 逐点抄读失败仅影响该点。区间抄读失败仅影响被覆盖且本轮未成功补读的点。串口和 MQTT 透传都区分收到的合法异常响应与通信故障。写命令成功和连接健康状态不改变采样品质。品质变化绕过死区，仅在 DataCenter 接受发布后推进上报基线。

RTU 提供 `quality_flags`，由 DataCenter 推导兼容摘要。104 主动上送与总召优先使用明细品质，字段缺席时按旧枚举处理。遥信保留 IV、NT、SB、BL，遥测另支持 OV。主动上送判重包含实际品质位，同点品质变化不被遥测合批覆盖，SOE 回放保留事件记录的品质。上位机消费 DataCenter 品质时应区分字段缺席与显式零，按位解释明细。

验收覆盖首次无值时省略、正常 `100/0x00`、超时 `100/0x40`、设备异常 `100/0xC0` 及恢复 `100/0x00`。同时验证区间与单点影响范围、保留旧样本时标、发布失败重试、同值恢复及旧枚举兼容。SB、BL、OV 由相应业务依据生成，RTU 普通采集不推断这些标志。
