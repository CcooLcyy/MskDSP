# IEC104 无路由模拟数据对点方案

## 目标

在不配置 DataCenter Route 的情况下，由 IEC104 从站直接向主站提供一批固定测试值，用于核对点表中的 IOA、类型、品质、时标和总召/主动上送报文。

## 范围

- 仅支持 `STATION_ROLE_SLAVE` 链路，传输角色可以是 `ROLE_SERVER` 或 `ROLE_CLIENT`。
- 仅覆盖现有点表支持的短浮点遥测和单点遥信。
- 模拟值由 IEC104 后端生成，每次生成后保持不变；再次生成才替换。
- 模拟值只保存在 IEC104 运行内存中，不写 SQLite、不写 DataCenter、不创建或修改 Route，也不进入配置导出。
- 不提供周期变化或波形；每次生成都会形成一份新的固定快照。
- 遥信（SINGLE）支持独立的模拟方式：随机、全部置 `true`、全部置 `false`、按当前值取反。
- 遥测（FLOAT）仍支持固定随机值和按 IOA 递增；遥信方式不会改变遥测值的生成规则。
- 点表通过独立业务类型区分遥信、遥测、遥调、遥控与参数；业务类型不替代 `FLOAT`/`SINGLE` 协议数据类型。
- 模拟仅覆盖业务类型为遥信、遥测的点；遥调、遥控、参数和未分类点不进入模拟快照，也不会由“应用并发送”发送模拟点值。
- 为兼容旧点表，缺少业务类型的点仅在既有 IOA 分类区间内推导类型；未分类 IOA 保持未分类且不参与模拟。业务类型为显式配置时，不按 IOA 区间限制，支持自定义地址规划。

## 运行语义

1. 上位机先配置链路和点表，DataCenter Route 可以保持为空。
2. 调用生成接口后，IEC104 仅对业务类型为遥测、遥信的点按所选模式生成一份固定值：随机模式的 FLOAT 使用 `[0,100]` 工程量范围；递增模式的 FLOAT 遥测点按 IOA 升序排列，仅对实际存在的模拟点连续编号，首点为 `1`，后续依次为 `2、3...`。SINGLE 遥信按遥信模拟方式生成：随机方式以随机布尔值填充；全部 `true`/全部 `false` 将可模拟遥信统一置为对应值；取反方式将可模拟遥信的当前值逐点取反。遥调、遥控、参数和未分类点不生成模拟值。所有生成值的品质统一为 GOOD。
3. 取反方式的“当前值”按以下顺序确定：优先使用该链路已有模拟快照中的遥信值；没有模拟快照值时读取 DataCenter 的最新值。若某个遥信两处都没有当前值，生成请求返回错误且不替换原有模拟快照，避免把未知值默认为 `false`。
4. 应用接口将当前快照作为不带时标的普通点值发送给已建立的 IEC104 主站连接：遥信使用 `M_SP_NA_1`（类型 1），遥测使用 `M_ME_NC_1`（类型 13），均为自发上送 `COT=3`，不受连接 `point_with_time` 开关影响；发送时 FLOAT 按点表 `scale/offset` 反向换算为协议原始值。模拟遥信不进入 SOE 历史或断线补传，提交发送时仍更新变位基线，避免清除模拟值后漏报真实状态。
5. 主站发起总召时，IEC104 对模拟快照中的点使用模拟值，其他点继续读取 DataCenter 目的端缓存。
6. 模拟快照存在期间，DataCenter 真实点值仅在 Tag 已被模拟快照覆盖时不向该 IEC104 连接主动上送；未模拟的遥调、遥控等点保持真实上送路径。
7. 清除接口删除模拟快照，后续恢复 DataCenter 真实点值订阅；停止链路会保留快照，删除连接、替换点表或重启模块会清除快照。

## 上位机交互

IEC104 页面在点表区域提供“模拟数据”面板。遥测选择“固定随机值”或“按 IOA 递增”；遥信选择“随机”“全部为真”“全部为假”或“当前值取反”，然后生成模拟值。面板提供“生成模拟值”“应用并发送”“清除模拟值”“重新读取”。取反需要每个遥信存在模拟快照值或 DataCenter 当前值；缺少当前值时显示后端错误，不生成不完整快照。非从站、无点表或链路未运行时，相关操作按后端状态禁用或返回明确错误。

## 验收标准

- Route 为空时，生成、查询、应用和总召均可使用同一批固定模拟值。
- “应用并发送”在连接 `point_with_time=false/true` 时均发送不带时标的类型 1 遥信与类型 13 遥测，值、品质、IOA 和倍率换算正确；重复点击仍发送完整快照，不生成 SOE 记录。
- 真实遥信变位仍使用带时标 SOE，并保留原有持久化、确认及断线补传；普通订阅与总召的时标配置不受本次修改影响。
- 遥调、遥控点不会进入模拟快照，点击“应用并发送”不会发送它们的模拟点值报文。
- 模拟期间，未包含在模拟快照中的点仍保持 DataCenter 真实上送和总召路径。
- 再次查询不会改变值；再次生成后值才替换。
- 全部为真/全部为假会覆盖快照中的所有遥信，遥测值保持所选遥测模式生成的结果。
- 取反对每个遥信逐点执行布尔取反；已模拟的点取反后仍保留在快照中，未模拟的点从 DataCenter 当前值补齐。
- 取反遇到无当前值的遥信时返回明确错误，原快照保持不变。
- 清除后不再发送模拟值，真实 DataCenter 订阅路径可继续工作。
- 主站链路不能调用模拟接口。

## 不带时标发送修正（2026-10-20）

现场“应用并发送”将模拟遥信送入 SOE 路径，导致连接关闭时标时仍发送类型 30，而重连总召发送类型 1，两个操作的对点表现不同。本次仅修正应用接口的发送方式，保留生成、查询、清除和总召的接口及快照语义。

实现顺序为：校验并构造完整快照（包括固定点排除与 FLOAT 反向缩放）→通过独立批量入口显式选择不带时标组包→同步遥信基线。批量组包复用既有拆分、SQ 编码、发送窗口及报文日志，不改写连接的时标配置。无连接、非从站、无模拟值、链路未运行和缩放失败等错误继续按现有接口返回；接口成功表示已提交发送，不代表对端业务已处理。

回归检查应先补测试，再实现：通过实际回环 socket 验证带时标连接下混合模拟点仍发类型 1/13、重复快照可再次发出，随后普通点值及真实 SOE 仍带时标；应用接口测试验证有 SOE 存储时不新增模拟事件，并保留模拟遥信基线。当前 Windows 工作机没有下位机编译环境，本次不搭建工具链、不自动使用远端编译或部署；无法运行的 GTest 明确记录为待验证。
