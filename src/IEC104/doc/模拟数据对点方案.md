# IEC104 无路由模拟数据对点方案

## 目标

在不配置 DataCenter Route 的情况下，由 IEC104 从站直接向主站提供一批固定的随机测试值，用于核对点表中的 IOA、类型、品质、时标和总召/主动上送报文。

## 范围

- 仅支持 `ROLE_SERVER + STATION_ROLE_SLAVE` 链路。
- 仅覆盖现有点表支持的短浮点遥测和单点遥信。
- 模拟值由 IEC104 后端生成，每次生成后保持不变；再次生成才替换。
- 模拟值只保存在 IEC104 运行内存中，不写 SQLite、不写 DataCenter、不创建或修改 Route，也不进入配置导出。
- 首版不做周期变化、翻转或波形。

## 运行语义

1. 上位机先配置链路和点表，DataCenter Route 可以保持为空。
2. 调用生成接口后，IEC104 按所选模式生成一份固定值：随机模式的 FLOAT 使用 `[0,100]` 工程量范围；递增模式的 FLOAT 点按 IOA 升序排列，仅对实际存在的遥测点连续编号，首点为 `1`，后续依次为 `2、3...`；两种模式的 SINGLE 都生成固定 `true/false`，品质统一为 GOOD。
3. 应用接口将当前快照直接发送给已建立的 IEC104 主站连接；发送时 FLOAT 按点表 `scale/offset` 反向换算为协议原始值。
4. 主站发起总召时，IEC104 优先使用当前模拟快照，不读取 DataCenter 目的端缓存。
5. 模拟快照存在期间，DataCenter 真实点值不向该 IEC104 连接主动上送，避免两种数据源混合。
6. 清除接口删除模拟快照，后续恢复 DataCenter 真实点值订阅；停止链路会保留快照，删除连接、替换点表或重启模块会清除快照。

## 上位机交互

IEC104 页面在点表区域提供“模拟数据”面板，选择“固定随机值”或“按 IOA 递增”后生成模拟值，并提供“生成模拟值”“应用并发送”“清除模拟值”“重新读取”。非从站服务端、无点表或链路未运行时，相关操作按后端状态禁用或返回明确错误。

## 验收标准

- Route 为空时，生成、查询、应用和总召均可使用同一批固定模拟值。
- 再次查询不会改变值；再次生成后值才替换。
- 清除后不再发送模拟值，真实 DataCenter 订阅路径可继续工作。
- 主站链路不能调用模拟接口。
