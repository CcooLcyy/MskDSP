# IEC104 无路由模拟数据对点方案

## 目标

在不配置 DataCenter Route 的情况下，由 IEC104 从站直接向主站提供一批固定测试值，用于核对点表中的 IOA、类型、品质、时标和总召/主动上送报文。

## 范围

- 仅支持 `STATION_ROLE_SLAVE` 链路，传输角色可以是 `ROLE_SERVER` 或 `ROLE_CLIENT`。
- 仅覆盖现有点表支持的短浮点遥测和单点遥信。
- 模拟值由 IEC104 后端生成，每次生成后保持不变；再次生成才替换。
- 模拟值只保存在 IEC104 运行内存中，不写 SQLite、不写 DataCenter、不创建或修改 Route，也不进入配置导出。
- 不提供周期变化或波形；每次生成都会形成一份新的固定快照。
- 遥信（SINGLE）支持独立的模拟方式：随机、全部置 `true`、全部置 `false`、按当前值取反。
- 遥测（FLOAT）仍支持固定随机值和按 IOA 递增；遥信方式不会改变遥测值的生成规则。

## 运行语义

1. 上位机先配置链路和点表，DataCenter Route 可以保持为空。
2. 调用生成接口后，IEC104 按所选模式生成一份固定值：随机模式的 FLOAT 使用 `[0,100]` 工程量范围；递增模式的 FLOAT 点按 IOA 升序排列，仅对实际存在的遥测点连续编号，首点为 `1`，后续依次为 `2、3...`。SINGLE 按遥信模拟方式生成：随机方式以随机布尔值填充；全部 `true`/全部 `false` 将点表中的每个遥信统一置为对应值；取反方式将每个遥信的当前值逐点取反。所有生成值的品质统一为 GOOD。
3. 取反方式的“当前值”按以下顺序确定：优先使用该链路已有模拟快照中的遥信值；没有模拟快照值时读取 DataCenter 的最新值。若某个遥信两处都没有当前值，生成请求返回错误且不替换原有模拟快照，避免把未知值默认为 `false`。
4. 应用接口将当前快照直接发送给已建立的 IEC104 主站连接；发送时 FLOAT 按点表 `scale/offset` 反向换算为协议原始值。
5. 主站发起总召时，IEC104 优先使用当前模拟快照，不读取 DataCenter 目的端缓存。
6. 模拟快照存在期间，DataCenter 真实点值不向该 IEC104 连接主动上送，避免两种数据源混合。
7. 清除接口删除模拟快照，后续恢复 DataCenter 真实点值订阅；停止链路会保留快照，删除连接、替换点表或重启模块会清除快照。

## 上位机交互

IEC104 页面在点表区域提供“模拟数据”面板。遥测选择“固定随机值”或“按 IOA 递增”；遥信选择“随机”“全部为真”“全部为假”或“当前值取反”，然后生成模拟值。面板提供“生成模拟值”“应用并发送”“清除模拟值”“重新读取”。取反需要每个遥信存在模拟快照值或 DataCenter 当前值；缺少当前值时显示后端错误，不生成不完整快照。非从站、无点表或链路未运行时，相关操作按后端状态禁用或返回明确错误。

## 验收标准

- Route 为空时，生成、查询、应用和总召均可使用同一批固定模拟值。
- 再次查询不会改变值；再次生成后值才替换。
- 全部为真/全部为假会覆盖快照中的所有遥信，遥测值保持所选遥测模式生成的结果。
- 取反对每个遥信逐点执行布尔取反；已模拟的点取反后仍保留在快照中，未模拟的点从 DataCenter 当前值补齐。
- 取反遇到无当前值的遥信时返回明确错误，原快照保持不变。
- 清除后不再发送模拟值，真实 DataCenter 订阅路径可继续工作。
- 主站链路不能调用模拟接口。
