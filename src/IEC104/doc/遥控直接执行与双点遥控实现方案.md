# IEC104 直接遥控与双点遥控实现方案

## 目标

IEC104 模块在现有 `C_SC_NA_1` 单点遥控基础上，支持：

- 单点遥控与双点遥控 `C_DC_NA_1`；
- 每个遥控点独立配置直接执行或选择执行（SBO）；
- 主站 SBO 严格等待选择阶段的正激活确认后，才发送执行阶段；
- 从站对直接执行、选择执行、选择超时、命令值不一致及非法双点状态给出正确确认。

旧点表不含新字段时，按“单点遥控 + 选择执行”解释，保持现有主站配置的行为。

## 范围与边界

- 仅增加 IEC104 的 `C_DC_NA_1`（Type ID `46`），不把双点遥控误作双点遥信。
- `PointType` 继续表示点值传输类型（FLOAT/SINGLE），不新增双点点值类型；遥控命令类型由独立字段描述。
- 新字段仅对 `POINT_BUSINESS_TYPE_REMOTE_CONTROL` 有意义；非遥控点规范化为默认值。
- `DataCenter` 不改协议。双点遥控的 DataCenter 值使用 `int64`：`1=分`、`2=合`；为便于既有 BOOL 控制点接入，BOOL `false/true` 分别兼容映射为 `1/2`。
- C_SE_NC_1 短浮点设点不在本次改变其现有选择语义。

## 配置模型

在 `IEC104Proto.Point` 新增：

```protobuf
enum RemoteControlType {
  REMOTE_CONTROL_TYPE_UNSPECIFIED = 0;
  REMOTE_CONTROL_TYPE_SINGLE = 1;
  REMOTE_CONTROL_TYPE_DOUBLE = 2;
}

enum CommandExecutionMode {
  COMMAND_EXECUTION_MODE_UNSPECIFIED = 0;
  COMMAND_EXECUTION_MODE_DIRECT = 1;
  COMMAND_EXECUTION_MODE_SELECT_EXECUTE = 2;
}
```

并以 `remote_control_type`、`command_execution_mode` 保存到每个点。空值分别规范化为 `SINGLE`、`SELECT_EXECUTE`，使旧配置兼容。

## 协议语义

| 命令 | Type ID | 状态字段 | 合法状态 |
| --- | ---: | --- | --- |
| 单点遥控 `C_SC_NA_1` | 45 | SCO bit0 | 0=分/否，1=合/是 |
| 双点遥控 `C_DC_NA_1` | 46 | DCO bit0~1 | 1=分，2=合；0、3 拒绝 |

两种命令的 bit7 都是 `S/E`：

- 直接模式：主站发送一次 `S/E=0`；从站立即同步执行业务回调，成功后发送 ACT_CON 与 ACT_TERM。
- SBO 模式：主站先发送 `S/E=1`，只在收到同类型、同 IOA、同命令值的正 ACT_CON 后发送 `S/E=0`。从站在选择阶段仅记录待执行命令并回 ACT_CON；执行阶段必须在 10 秒内匹配，失败时回否定 ACT_CON。
- 从站按点表的 `command_execution_mode` 校验执行阶段：配置为 `SELECT_EXECUTE` 时，没有有效预置的 `S/E=0` 必须返回否定 ACT_CON 且不得触发业务回调；配置为 `DIRECT` 时允许裸 `S/E=0`，也允许完整的 `S/E=1 -> S/E=0` 流程。
- 收到无效 DCO、类型/值不匹配、选择超时或选择阶段的否定确认时，不执行业务回调并记录中文日志。

## 实现划分

1. 点表与配置：扩展两份 IEC104 proto、PointTable 内存模型、校验、持久化和 ConfigPusher/上位机 DTO。
2. 会话协议：增加 Type ID 46、DCO 编解码、通用的待选命令状态和主站等待确认状态机。
3. 命令路由：LinkManager 根据点表的业务类型、遥控类型和执行方式分发命令；从站将双点状态转换为 DataCenter `int64` 或兼容 BOOL。
4. 上位机：遥控点编辑页、批量编辑、导入导出和浏览器 mock 贯通两个新字段；非遥控点不展示该配置。
5. 文档与测试：更新协议说明、配置示例和未实现清单；新增会话、点表、命令路由、上位机工作流测试。

## 验收标准

- 旧单点遥控配置仍按 SBO 运行。
- 配置为直接单点/双点时，一条 `S/E=0` 命令会执行并返回 ACT_CON、ACT_TERM。
- 配置为 SBO 单点/双点时，执行帧只能在选择正确认后发送；裸 `S/E=0`、超时、拒绝或不匹配均不得执行。
- 配置为直接单点/双点时，裸 `S/E=0` 与完整选择后执行流程均可执行。
- 双点 Type ID 为 46，DCO 只接受 1 和 2，确认帧回显同一 DCO 与 S/E。
- 点表、持久化、上位机保存/加载和配置导入导出均不丢失新字段。
